## 1. 발표용 그래프 6종 (`results/figures/step6_final/`)

기존 그래프를 점검한 결과 레이블 겹침이나 단위 문제가 없어서 **원본을 그대로 복사**했습니다.
- 형식: PNG 300 dpi + PDF
- 원본 출처는 `SOURCES.json`에 적었고, 원본과 MD5가 같은지 확인했습니다.
- 원본 그래프 데이터(`final_plot_data_*.csv`, `criteo_final_test_*.csv`)가 결과 요약표와 일치하는지도 확인했습니다.

> 시뮬레이션 그래프(1~3)의 y축은 **정답 대비 오차 RMSE(낮을수록 좋음)**, Criteo 그래프(4~6)의 y축은 **타기팅 증분 전환(높을수록 좋음)** 입니다. 두 그래프 묶음을 같은 성능 척도처럼 나란히 비교하지 않도록, 발표에서 척도가 바뀐다는 점을 명시해야 합니다.

### 그래프 1. `fig1_sim_sample_size_rmse` — 표본 크기에 따른 RMSE

| 항목 | 내용 |
|---|---|
| 실험 조건 | 시뮬레이션 c00·c01·c02 (n=1k / 10k / 100k), 처치 50%, 선형 효과, 조건별 30회 |
| X축 | 표본 크기(로그 축) |
| Y축 | 평균 RMSE (정답 CATE 대비, 낮을수록 좋음). 오차막대는 30회 평균의 95% CI |
| 핵심 관찰 | 세 모델 모두 단조 감소. CF 0.209 → 0.062(−70%). Constant ATE는 약 0.30에서 거의 변화 없음 |
| 통계 주의 | 모든 감소는 짝비교 + Holm에서 유의. 테스트 세트도 n에 비례해 커지므로 오차막대 축소의 일부는 측정 잡음 감소 |
| 핵심 문장 | "데이터가 많을수록 세 모델 모두 정확해지며, 개선 폭은 Causal Forest가 가장 큽니다." |

### 그래프 2. `fig2_sim_treatment_ratio_rmse` — 처치군 비율에 따른 RMSE

| 항목 | 내용 |
|---|---|
| 실험 조건 | 시뮬레이션 c01·c03·c04 (처치 50% / 30% / 10%), n=10,000, 선형 효과 |
| X축 | 처치군 비율(0.5 → 0.1) |
| Y축 | 평균 RMSE (낮을수록 좋음), 95% CI 오차막대 |
| 핵심 관찰 | 10%에서 세 모델 모두 악화(T +13.5%, X +32.4%, CF +48.8%). T-Learner(0.320)는 Constant ATE(0.302)보다 위로 올라감 |
| 통계 주의 | 0.5 → 0.3 구간은 X만 유의. T와 CF의 작은 증가는 통계적으로 확인되지 않음 |
| 핵심 문장 | "처치군이 10%로 줄면 T-Learner는 '모두에게 같은 효과'를 예측하는 기준선보다도 부정확해집니다." |

### 그래프 3. `fig3_sim_effect_structure_rmse` — 효과 구조별 RMSE

| 항목 | 내용 |
|---|---|
| 실험 조건 | 시뮬레이션 c01·c05·c06 (선형 / 비선형 / 상호작용), n=10,000, 처치 50% |
| X축 | 효과 구조 |
| Y축 | 평균 RMSE (낮을수록 좋음), 95% CI 오차막대 |
| 핵심 관찰 | 선형에서는 CF가 압도적(0.107). 비선형·상호작용에서는 CF 오차가 약 2배로 증가. 상호작용에서는 X(0.217) < CF(0.242) |
| 통계 주의 | **비선형에서 X(0.203)와 CF(0.209)의 차이는 유의하지 않음**(Holm p = 0.106). 막대 높이 차이만으로 X가 낫다고 말하지 말 것. 상호작용 X 우위는 RMSE 기준(MAE에서는 차이 없음) |
| 핵심 문장 | "최적 모델은 효과 구조에 따라 바뀌었습니다. 선형에서는 Causal Forest, 상호작용에서는 X-Learner, 비선형에서는 우열을 가릴 수 없었습니다." |

### 그래프 4. `fig4_criteo_test_qini_curve` — 최종 테스트 Qini curve

| 항목 | 내용 |
|---|---|
| 실험 조건 | Criteo 최종 테스트 2,795,918명, 300k 학습 모델 3개, 무작위 타기팅 직선 |
| X축 | 타기팅 비율(예측 uplift 상위 %) |
| Y축 | Qini Q(k): 상위 k명 중 처치군의 증분 전환 건수(대조군을 처치군 규모로 환산) |
| 핵심 관찰 | 세 곡선 모두 무작위 직선보다 위에 있고, 상위 10~20%에서 빠르게 상승. X와 CF 곡선은 거의 겹치고, T는 그 아래 |
| 통계 주의 | 곡선 자체에는 신뢰구간이 없음(그래프 5 참고). 오른쪽 끝(하위 약 3~5%)의 급상승은 사후 탐색 대상이며 결론에 사용하지 않음 |
| 핵심 문장 | "세 모델 모두 무작위 타기팅보다 증분 전환을 많이 찾아냈고, X-Learner와 Causal Forest의 곡선은 거의 같습니다." |

### 그래프 5. `fig5_criteo_test_qini_coefficient_ci` — 모델별 Qini coefficient와 95% CI

| 항목 | 내용 |
|---|---|
| 실험 조건 | Criteo 최종 테스트, 처치·대조 층화 짝 부트스트랩 B=1,000 |
| X축 | Qini coefficient(전환 건수, 무작위 = 0) |
| Y축 | 모델 |
| 핵심 관찰 | T 399 [230, 565], X 692 [529, 858], CF 685 [522, 847]. 세 구간 모두 0보다 큼 |
| 통계 주의 | **모델별 구간이 겹친다고 차이가 없다는 뜻은 아님.** 판단은 짝비교로 해야 함: X − T, CF − T는 Bonferroni 후 유의, CF − X는 비유의. 학습 seed 변동은 반영되지 않음 |
| 핵심 문장 | "세 모델 모두 무작위보다 우수했고, X-Learner와 Causal Forest는 T-Learner보다 유의하게 높았지만 서로 간의 차이는 확인되지 않았습니다." |

### 그래프 6. `fig6_criteo_test_targeting` — 상위 타기팅 비율별 증분 전환

| 항목 | 내용 |
|---|---|
| 실험 조건 | Criteo 최종 테스트, 상위 10 / 20 / 30% 타기팅, 무작위 타기팅 비교 |
| X축 | 타기팅 비율 |
| Y축 | 추정 증분 전환 건수 = (처치군 전환율 − 대조군 전환율) × 타기팅 인원. 오차막대는 부트스트랩 95% CI |
| 핵심 관찰 | 상위 10%: T 1,677 / X 1,905 / CF 1,934 vs 무작위 322(약 5~6배). 비율이 커질수록 T와의 격차 확대 |
| 통계 주의 | 상위 10%에서는 모델 간 차이가 보정 후 유의하지 않음. 20·30%에서 X·CF > T는 유의(2차 지표, 지표 간 보정 없음). 증분 전환은 **캠페인 배정 효과(ITT)** 기준 추정치이며 실제 노출 효과나 매출이 아님 |
| 핵심 문장 | "예측 상위 10% 고객만 공략해도 무작위 대비 약 5~6배의 증분 전환이 추정됩니다." |

## 3. PPT 제작 시 활용할 핵심 메시지

**연구 동기 (1줄)**
- "누구에게 광고를 보여야 효과가 클까?" 고객별 처치효과(CATE)를 추정하는 세 모델이 데이터 특성에 따라 어떻게 달라지는지 비교했습니다.

**설계 (2줄)**
- 정답을 아는 시뮬레이션: 7개 조건 × 30회 반복, 정답 대비 오차(RMSE)
- 실제 Criteo 광고 데이터 1,398만 명: 테스트 279만 명에서 한 번만 평가, 타기팅 성과(Qini)

**핵심 발견**
1. 데이터가 많을수록 모두 정확해지고, Causal Forest가 가장 크게 개선(−70%)되었습니다.
2. 처치군이 부족하면 T-Learner는 단순 기준선보다도 나빠졌습니다.
3. 최적 모델은 효과 구조에 따라 달랐습니다. 선형은 CF, 상호작용은 X, 비선형은 구분 불가입니다.
4. 실제 데이터에서도 모두 무작위보다 우수했고, X·CF가 T보다 유의하게 우수했습니다(X vs CF는 차이 없음).
5. 상위 10%만 타기팅해도 증분 전환이 무작위의 약 5~6배였습니다.

**마무리 메시지**: 데이터 특성에 맞는 CATE 모델 선택이 효율적인 타기팅의 출발점입니다.

**발표에서 피해야 할 표현**
- "Causal Forest가 가장 좋은 모델이다" → 실제 데이터에서 X와 구분되지 않았고, 상호작용 조건에서는 X가 더 정확했습니다.
- "비선형에서 X-Learner가 더 좋다" → 유의하지 않았습니다.
- "광고를 보면 전환이 N건 늘어난다" → 배정 효과(ITT)이고, 실제 노출은 처치군의 3.6%입니다.
- "시뮬레이션 RMSE와 실제 Qini를 비교하면…" → 서로 다른 척도입니다.
- "새로운 알고리즘을 제안했다" → 기존 모델의 체계적 비교 연구입니다.
