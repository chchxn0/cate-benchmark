### 시뮬레이션: 입증된 것과 입증되지 않은 것

**입증됨** (이 데이터 생성 구조, 고정 하이퍼파라미터, 30회 반복, 짝비교 + Holm 기준)
1. 표본 크기가 커지면 세 모델 모두 CATE RMSE가 감소합니다.
2. 처치군 비율이 10%로 줄면 세 모델 모두 RMSE가 증가합니다.
3. T-Learner는 세 모델 중 RMSE가 가장 큽니다(7개 조건 모두). n=1,000과 p=0.1에서는 이질성을 무시한 Constant ATE보다도 나쁩니다.
4. 선형 효과에서는 Causal Forest의 RMSE가 가장 낮습니다(5개 조건 모두 유의).
5. 상호작용 효과에서는 X-Learner의 RMSE가 Causal Forest보다 낮습니다.

**입증되지 않음**
- 비선형 효과에서 X-Learner와 Causal Forest의 우열(RMSE와 MAE 모두 유의하지 않음)
- 상호작용 조건에서 X 우위가 MAE에서도 성립하는지(보조 분석에서 차이 없음)
- 요인을 동시에 바꿀 때의 결과(OFAT라 교호작용 미검증)
- 다른 데이터 생성 구조, 다른 하이퍼파라미터, 교란이 있는 관측 데이터에서도 같은 결과가 나오는지
- 처치 비율 0.5 → 0.3에서 T와 CF의 변화(유의하지 않음)

- 타기팅 비율별 비교는 2차 지표라 지표 간 다중성 보정을 하지 않았습니다.

### Criteo: 확인된 것과 확인되지 않은 것

**확인됨** (테스트 표본 변동 범위, 사전 고정 기준)
1. 세 모델 모두 무작위 타기팅보다 Qini coefficient가 높습니다.
2. X-Learner와 Causal Forest는 T-Learner보다 높습니다(Bonferroni 보정 후 유의).
3. Causal Forest > T-Learner는 검증과 테스트 모두에서 유의했습니다.

**확인되지 않음**
- X-Learner와 Causal Forest의 우열(검증 +147, 테스트 −6, 모두 비유의)
- 상위 10% 구간의 모델 간 차이(보정 후 0 포함)
- 학습 seed나 표본을 바꿔도 결과가 유지되는지(모델당 1회 학습)
- 1M 이상의 학습 규모에서의 결과

## 3. 검증 중 발견한 사항

새로 발견한 수치 오류는 없습니다. 다만 다음 서술은 보완이 필요하거나 갱신되지 않은 상태입니다.

1. **T-Learner가 Constant ATE보다 나빴던 조건은 c04만이 아니라 c00(n=1,000)도 포함됩니다.** STEP 5-6 보고서 6절의 시뮬레이션 비교는 c04만 언급합니다. 틀린 서술은 아니지만 불완전합니다. 이 문서와 STEP 6 결론에서는 두 조건을 모두 반영했습니다.
2. **상호작용 조건의 "X-Learner가 Causal Forest보다 유의하게 정확" 서술은 RMSE 기준입니다.** 보조 MAE 분석에서는 차이가 없었으므로(p = 0.87), STEP 6 문서에서는 "RMSE 기준"으로 한정했습니다.
3. **`README.md`는 STEP 5(Criteo)를 "미실시"로 표시하고, pytest 수를 79개로 적고 있습니다.** 현재는 Criteo가 완료되었고 테스트는 112개입니다. 이번 단계는 기존 파일을 수정하지 않는 범위라 README는 바꾸지 않았습니다. 발표 전에 갱신할 것을 권장합니다.
4. 비례 층화 배분 때문에 Criteo 검증·테스트 세트의 층별 인원과 전환 수가 정확히 같습니다(7,342 / 813). 그래서 전체 증분 $U(N)$ = 3,217.6도 같습니다. 오류가 아니라 설계상 결과입니다.
