## ① 연구 배경과 문제 정의

광고·쿠폰·추천처럼 "누구에게 개입할지"를 정해야 하는 문제에서는, 개입이 평균적으로 효과가 있는지(ATE)보다 **고객마다 효과가 얼마나 다른지**가 더 중요합니다. 이 차이를 추정하는 모델은 여러 가지가 있지만, 데이터 특성에 따라 어떤 모델이 더 정확하고 안정적인지는 상황마다 다릅니다.

**연구 질문**: 표본 크기, 처치군 비율(불균형), 처치효과의 구조가 달라질 때 T-Learner, X-Learner, Causal Forest의 CATE 추정 성능은 어떻게 달라지는가? 그리고 실제 광고 데이터에서도 차이가 나타나는가?

**두 단계로 설계한 이유**
- 실제 데이터에는 고객별 정답 효과(참 CATE)가 없어 정확도를 직접 잴 수 없습니다. 그래서 먼저 **정답을 아는 시뮬레이션**에서 데이터 특성을 하나씩 바꿔 가며 정확도(RMSE)를 비교했습니다.
- 이어서 **실제 Criteo 광고 데이터**에서 정답 없이 쓸 수 있는 타기팅 지표(Qini·AUUC)로 실용적인 성능을 확인했습니다.

## ② CATE와 인과추론 개념

- **잠재 결과**: 고객 $i$에게 처치했을 때의 결과 $Y_i(1)$과 하지 않았을 때의 결과 $Y_i(0)$. 실제로는 둘 중 하나만 관측됩니다.
- **ATE**: $E[Y(1)-Y(0)]$. 전체 평균 효과입니다.
- **CATE**: $\tau(x)=E[Y(1)-Y(0)\mid X=x]$. 특성 $x$를 가진 고객의 평균 효과입니다.
- **무작위 배정**이면 처치가 특성과 무관하므로, 같은 특성 구간 안에서 처치군과 대조군의 결과 차이로 효과를 추정할 수 있습니다. 시뮬레이션과 Criteo 모두 무작위 배정 데이터를 써서 교란 변수 문제를 배제했습니다.

## ③ 비교 모델과 선정 이유

| 모델 | 방식 | 선정 이유 |
|---|---|---|
| T-Learner | 처치군·대조군 결과 모델을 따로 학습하고 예측 차이를 사용 | 가장 단순한 기준 메타러너 |
| X-Learner | T-Learner 결과로 고객별 대리 효과를 만들고 다시 학습한 뒤 성향점수로 가중 결합 | 처치군·대조군 크기가 불균형할 때를 위해 제안된 방법(Künzel et al., 2019) |
| Causal Forest | 효과 차이를 직접 분할 기준으로 쓰는 포레스트, 교차적합·honest 추정 (`econml` CausalForestDML) | 이질적 효과 추정을 위한 대표적인 포레스트 방법(Wager & Athey, 2018; Athey et al., 2019) |
| (기준선) Constant ATE | 모든 고객에게 같은 평균 효과를 예측 | "이질성을 학습해서 실제로 얻는 것이 있는가"를 확인하기 위한 비교 대상 |

공정한 비교를 위해 다음 조건을 세 모델에 똑같이 적용했습니다.
- 기본 학습기는 모두 RandomForest(200그루, `min_samples_leaf=5`)입니다.
- 하이퍼파라미터는 실험 전에 고정했고, 조건별 튜닝은 하지 않았습니다.
- 같은 반복 안에서는 같은 데이터와 같은 분할을 사용했습니다.

## ④ 시뮬레이션 데이터 생성

- **X**: $X_1,\dots,X_{10}\sim N(0,1)$. $X_4$~$X_{10}$은 결과에 영향이 없는 잡음 변수입니다.
- **T**: Bernoulli($p$)로 무작위 배정합니다.
- **Y**: $Y=\mu_0(X)+T\,\tau(X)+\varepsilon$, 여기서 $\mu_0=0.2X_1-0.1X_2+0.3X_3$, $\varepsilon\sim N(0,1)$입니다.
- **정답 CATE**: $\tau(X)=0.5+0.3\,g(X)$입니다. $g$는 평균 0, 분산 1로 맞췄습니다. 그래서 세 효과 구조 모두 **평균 효과 0.5, 이질성 SD 0.3이 같고 함수 모양만** 다릅니다.
  - 선형: $g=X_1$
  - 비선형: 이차항(U자형) + 사인(주기형)을 표준화해 더한 형태
  - 상호작용: $g=X_1X_2$
  - 이렇게 맞춘 이유는 효과의 크기나 이질성 크기가 아니라 순수하게 "모양"의 영향만 보기 위해서입니다.
- **요인 수준**: 표본 크기 1,000 / 10,000 / 100,000, 처치군 비율 0.5 / 0.3 / 0.1, 효과 구조 linear / nonlinear / interaction.
- **정답의 사용 범위**: 정답 CATE는 테스트 채점에만 썼고, 모델 입력은 X, T, Y뿐입니다(누수 방지를 단위 테스트로 확인).

## ⑤ 시뮬레이션 실험 설계

- **OFAT 설계**: 기준 조건(n=10,000, p=0.5, linear)을 두고 한 번에 한 요인만 바꿔 **7개 고유 조건**(c00~c06)을 만들었습니다.
  - 27개 조건 전체 요인설계는 n=100,000 조건의 계산 비용(반복 1회 약 12분) 때문에 실행하지 않았습니다.
- **반복**: 조건마다 30회, 총 210회(결과 840행) 반복했습니다.
  - 반복 r에서 데이터 seed = 42 + r, 모델 seed = 1000 + r입니다.
  - 같은 반복의 모델들은 같은 데이터와 80/20 분할(T로 층화)을 공유합니다. 이렇게 해서 모델 간 **짝비교**가 가능합니다.
- **지표**: 테스트 세트에서 정답 CATE 대비 **RMSE**(주 지표)와 MAE를 계산했습니다. 반복 간 SD는 안정성 지표로 썼습니다.
- **통계**
  - 반복 평균의 t 기반 95% 신뢰구간을 계산했습니다.
  - 같은 반복끼리 짝지은 t검정을 하고, 조건 내 6쌍에 Holm 보정을 적용했습니다.
  - 조건 간 비교도 짝비교로 했고, 비교 묶음별로 Holm 보정을 적용했습니다.
- **자원 관리**: n=100,000 조건은 메모리 감시(7 GB 상한)를 걸고 5회씩 나누어 실행했습니다. 반복 1회에 약 741초가 걸렸습니다.

## ⑥ 시뮬레이션 주요 결과 (요약)

- 표본이 커질수록 세 모델 모두 RMSE가 유의하게 감소했습니다. Causal Forest는 1k → 100k에서 −70.3%로 감소폭이 가장 컸습니다.
- 처치군 비율이 10%로 줄면 세 모델 모두 유의하게 나빠졌습니다. T-Learner는 이 조건(c04)과 n=1,000 조건(c00)에서 Constant ATE보다도 나빴습니다.
- 선형 효과 5개 조건에서는 Causal Forest의 RMSE가 가장 낮았습니다.
- 상호작용 조건에서는 X-Learner의 RMSE가 Causal Forest보다 유의하게 낮았습니다.
- 비선형 조건에서는 X-Learner와 Causal Forest의 RMSE 차이가 유의하지 않았습니다.

## ⑦ 실제 Criteo 데이터 선정과 전처리

- **데이터**: Criteo AI Lab의 Uplift Prediction Dataset **v2.1(erratum 반영 un-biased 수정판)**, 13,979,592행입니다.
  - 공식 페이지 링크가 끊겨 있어서 Criteo AI Lab의 공식 Hugging Face 저장소에서 받았습니다(SHA-256 확인).
  - 라이선스는 CC BY-NC-SA 4.0입니다.
- **변수**: X = f0~f11(익명 특성), T = treatment(캠페인 **배정**), Y = conversion.
  - visit과 exposure는 배정 이후에 정해지는 변수라 입력에서 제외했습니다.
  - 추정 대상은 **ITT 효과**입니다.
- **특성**
  - 처치 85% / 대조 15%로 불균형합니다.
  - 전환율은 0.292%로 매우 희귀합니다(대조군 전환은 전체 4,063건).
  - 원본 파일이 treatment별 연속 구간으로 정렬되어 있어서, 앞부분만 잘라 쓰면 편향된 표본이 됩니다.
- **분할**: treatment × conversion 4개 층으로 비례 층화 무작위 분할했습니다(seed 42). 최종 테스트 20%를 먼저 고정하고, 이어서 검증 20%, 학습 풀 60%로 나눴습니다.
  - 학습 후보는 100k ⊂ 300k ⊂ 1M 중첩 표본입니다.
  - 전환 사례 과대표집은 하지 않았습니다. 테스트 성능 평가가 왜곡되지 않도록 원래 비율을 유지했습니다.

## ⑧ 실제 데이터 모델 학습

- **같은 조건 적용**: STEP 4와 같은 모델 구현과 하이퍼파라미터, seed 42를 썼습니다. 이진 Y에서도 회귀 기반 결과 모델(확률 추정)이 그대로 유효한지 공식 API 기준으로 검토했습니다.
- **100k 파일럿**(학습 대조군 전환 29건)
  - 학습 시간: T 17초, X 51초, CF 201초. 최대 메모리 2.4 GB.
  - T-Learner 예측의 84.8%가 정확히 0이었습니다.
- **300k**(대조군 전환 87건)
  - 학습 시간: T 60초, X 177초, CF 726초. 최대 메모리 3.8 GB.
  - Causal Forest 포레스트 크기가 표본에 정확히 비례(×3.0)해서, 1M은 7 GB 보호 기준을 넘을 것으로 판단했습니다.
- **학습 규모 확정**: 세 모델이 모두 같은 설정으로 메모리 기준 안에서 돌아가는 가장 큰 규모인 **300k**로 정했습니다.

## ⑨ 실제 데이터 평가

정답 CATE가 없으므로 RMSE는 계산하지 않았습니다. 고객을 예측 효과 순으로 정렬해 타기팅 성과를 평가했습니다.

**지표**
- **Qini curve** $Q(k)$: 상위 k명 중 처치군의 증분 전환입니다. 대조군 전환을 처치군 규모로 환산해 빼므로 85:15 불균형이 보정됩니다.
- **Uplift curve**와 **AUUC**: 상위 k명 전원을 처치했을 때의 증분 전환과 그 면적입니다.
- **Qini coefficient**(주 지표): 무작위 타기팅 직선보다 위에 있는 면적입니다. 단위는 전환 건수이고, 무작위 = 0입니다.
- **상위 10/20/30% 증분 전환**도 함께 계산했습니다.
- 지표 정의와 동점 처리를 단위 테스트 16개로 확인한 뒤 사용했습니다.

**검증과 테스트 절차**
- 검증 세트에서 300k 모델로 B=1,000 층화 짝 부트스트랩을 실행했습니다.
- 그다음 최종 설정을 문서로 고정했습니다(모델 파일 SHA-256 기록).
- 마지막으로 테스트 세트(2,795,918명)를 **한 번만** 평가했습니다.

## ⑩ 최종 테스트 결과와 결론 (요약)

- **Qini coefficient**: T-Learner 399.2 [230, 565], X-Learner 691.7 [529, 858], Causal Forest 685.4 [522, 847]. 세 모델 모두 무작위 타기팅보다 우수합니다(95% CI > 0).
- **짝비교 (Bonferroni 보정)**: X − T와 CF − T는 유의했고, CF − X(−6.3)는 유의하지 않았습니다.
- **상위 10% 타기팅**: 증분 전환 1,677~1,934건으로, 무작위 타기팅(322건)의 약 5~6배입니다.
- **종합**: T-Learner는 시뮬레이션과 실제 데이터 모두에서 가장 약했습니다. X-Learner와 Causal Forest의 우열은 데이터 조건에 따라 달랐고, 실제 데이터에서는 구분되지 않았습니다.
