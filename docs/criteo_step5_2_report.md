# STEP 5-2 보고서: Criteo 데이터 분할 및 평가 파이프라인 준비

- 작성일: 2026-11-11
- 범위: 최종 테스트·검증·학습 후보 분할, 분할 검증, 실제 데이터용 uplift 평가 함수와 단위 테스트, 부트스트랩 비용 검토
- **T-Learner, X-Learner, Causal Forest는 학습하지 않았습니다.**
- 재현: `.venv/bin/python scripts/criteo_prepare.py` (약 27초, 최대 RSS 약 1.7 GB)

## 1. 연구 변수

| 역할 | 변수 | 비고 |
|---|---|---|
| X | `f0`~`f11` | 변환·제거 없음. `float32`로 로드 |
| T | `treatment` | 캠페인 배정. 추정 대상은 **ITT 효과** |
| Y | `conversion` | 유일한 주평가 결과 |
| 사용 안 함 | `visit`, `exposure` | 배정 이후 변수. X나 T로 쓰지 않으며, 분할 비교의 기술 통계에만 사용 |

`src/criteo_data.py::load_split`은 기본적으로 X, T, Y와 원본 행 번호(`row_id`)만 반환합니다. 실제 데이터에는 참 CATE가 없으므로 RMSE는 계산하지 않습니다.

## 2. 분할 방법

1. 원본에서 `treatment`, `conversion` 두 열만 읽어(int8) 4개 층을 만듭니다: `2 × treatment + conversion`.
2. `numpy.random.default_rng(42)`로 층마다 한 번씩 무작위 순열을 만듭니다(층 0→3 순서).
3. 각 층의 순열에서 차례로 떼어냅니다.
   - **앞부분 → 최종 테스트(20%)**
   - **다음 → 검증(20%)**
   - **나머지 → 학습 풀(60%, 무작위 순서 유지)**
4. 학습 후보 100k / 300k / 1M은 학습 풀 순서의 **앞부분(prefix)** 입니다. 따라서 100k ⊂ 300k ⊂ 1M ⊂ 학습 풀로 중첩됩니다.
5. 층별 배정 인원은 전체 데이터의 층 비율에 비례하며, 최대잉여법(largest remainder)으로 정수화합니다. 과대표집이나 복제는 없습니다.

원본 행 순서(treatment별 연속 구간)는 사용하지 않습니다. 최종 테스트는 가장 먼저 정해지며, 검증이나 학습 크기를 바꿔도 변하지 않습니다(단위 테스트로 확인).

**검증 세트 크기를 20%로 정한 이유.** 모델·설정 선택의 정밀도도 대조군 전환 수에 좌우됩니다. 그래서 테스트와 같은 규모(대조군 전환 813건)를 확보했습니다. 학습 풀은 600만 행 이상으로, 1M 학습 후보에 충분합니다. 검증 예측 비용이 크면 STEP 5-3에서 검증 세트의 층화 부분표본을 쓸 수 있습니다.

### 저장 형식

- `data/criteo/splits/{test,valid,train_pool,train_100000,train_300000,train_1000000}.npy`
- 정렬된 0-기반 원본 데이터 행 번호(헤더 제외), int32, 합계 59 MB
- Git 제외(`data/criteo/*`). 각 파일의 SHA256은 `criteo_split_metadata.json`에 있습니다.
- 데이터 복사본(CSV)은 만들지 않았습니다. 필요할 때 `load_split()`이 원본을 청크 단위로 읽어 해당 행만 가져옵니다.
- 스크립트를 다시 실행하면 같은 인덱스가 재생성되는지 비교만 하고 덮어쓰지 않습니다. 재실행 결과 6개 파일 모두 동일했습니다.

## 5. 평가 지표 정의 (`src/criteo_evaluation.py`)

하나의 모델이 낸 uplift 점수로 테스트 관측치를 **내림차순 정렬**합니다. 상위 $k$명(비율 $\phi = k/N$)에서 다음을 셉니다.
- $N_t(k), N_c(k)$: 처치군·대조군 인원
- $Y_t(k), Y_c(k)$: 처치군·대조군 전환 수

| 기호 | 정의 | 단위 | 의미 |
|---|---|---|---|
| $d(k)$ | $\dfrac{Y_t(k)}{N_t(k)} - \dfrac{Y_c(k)}{N_c(k)}$ | 전환율 차 | 상위 $k$명의 평균 처치효과 추정 |
| **Uplift curve** $U(k)$ | $d(k) \cdot k$ | 전환 건수 | 상위 $k$명 **전원**을 처치했을 때 대비 아무도 처치하지 않았을 때의 증분 전환 |
| **Qini curve** $Q(k)$ | $Y_t(k) - Y_c(k)\,\dfrac{N_t(k)}{N_c(k)} = d(k)\cdot N_t(k)$ | 전환 건수 | 상위 $k$명 중 **실제 처치군**에서의 증분 전환(대조군을 처치군 규모로 환산) |
| **AUUC** (원값) | $\int_0^1 U(\phi N)\,d\phi$ | 전환 건수 | 타기팅 깊이 전체에 걸친 평균 증분 전환 |
| AUUC 무작위 기준 | $U(N)/2$ | 전환 건수 | $(0,0)$–$(1, U(N))$ 직선 아래 면적 |
| AUUC − 무작위 | AUUC $- U(N)/2$ | 전환 건수 | 무작위 타기팅 대비 이득 |
| **정규화 AUUC** | $(\text{AUUC} - U(N)/2)\,/\,U(N)$ | 무단위 | 분모는 전체 증분 $U(N)$. **$U(N) \le 0$이면 NaN** |
| Qini 면적 | $\int_0^1 Q(\phi N)\,d\phi$ | 전환 건수 | |
| **Qini coefficient** | Qini 면적 $- Q(N)/2$ | 전환 건수 | 무작위 기준선 대비 면적 차이 |
| 정규화 Qini | Qini coefficient $/\,Q(N)$ | 무단위 | **$Q(N) \le 0$이면 NaN** |
| 상위 $q$% 증분 전환율 | $d(qN)$ | 전환율 차 | $q$ = 10, 20, 30% |
| 상위 $q$% 증분 전환 건수 | $d(qN) \times qN$ | 전환 건수 | 타기팅 집단의 전환율 차를 타기팅 인원 전체에 적용 |

**계산 규칙**
- **적분:** $\phi \in \{0, 0.01, \dots, 1\}$(101점)에서 사다리꼴 적분하며, $U(0)=Q(0)=0$입니다.
- **85:15 불균형:** 집단별 분모($N_t$, $N_c$)로 나누므로 반영됩니다. 단순 누적 건수 차 $Y_t - Y_c$는 사용하지 않습니다. 예를 들어 처치 17명 중 4건, 대조 3명 중 1건이면 단순 차는 3이지만 $Q = -1.67$입니다(단위 테스트로 확인).
- **대안 추정량(`estimator="ipw"`):** $U_{ipw}(k) = Y_t(k)/e - Y_c(k)/(1-e)$이며, $e$는 설계 배정 확률입니다(기본값은 해당 데이터의 처치 비율 ≈ 0.85). 집단이 비어 있어도 정의되지만 분산이 큽니다. 주 지표는 비율 추정량이고, IPW는 보조 확인용입니다. 전체 집단에서는 두 추정량이 일치합니다(테스트로 확인).
- **동점 점수:** 같은 점수의 관측치를 한 블록으로 묶고, 블록 안에서는 누적 건수를 선형 보간합니다. 이는 동점 순서를 무작위로 했을 때의 기댓값입니다. 입력 행 순서에 따라 결과가 달라지지 않습니다.
- **분모 0:** 어떤 격자점에서 $N_t(k)=0$ 또는 $N_c(k)=0$이면 그 점의 $d, U, Q$는 NaN입니다. 이때 면적도 NaN으로 두고, `n_undefined_points`로 개수를 보고합니다. 경고나 무한대는 발생하지 않습니다.

**인과적 해석에 필요한 가정.** $d(k)$를 "상위 $k$명의 평균 ITT 효과"로 읽으려면 다음이 성립해야 합니다.
1. 처치 배정이 X와 독립인 무작위 배정이다(STEP 5-1에서 SMD ≤ 0.049로 균형 확인).
2. SUTVA: 다른 사용자의 배정이 결과에 영향을 주지 않는다.
3. 점수가 X만의 함수이고, 평가 데이터를 쓰지 않고 학습되었다(그래서 점수 구간 안에서도 배정이 무작위로 유지된다).
4. 테스트 기간과 모집단이 타기팅 적용 상황과 같다.

추정 대상은 실제 노출 효과가 아니라 **캠페인 배정의 효과**입니다(처치군 중 실제 노출은 3.6%).

## 7. 부트스트랩 평가 설계와 비용

**설계.**
- 테스트 관측치를 처치군·대조군별로 복원추출합니다(각 집단 크기 고정).
- 추출 결과는 관측치별 **정수 가중치**로 표현해 데이터를 복사하지 않습니다.
- 모델별 정렬(argsort)은 한 번만 하고, 매 반복마다 같은 가중치를 세 모델에 적용합니다. 이렇게 하면 같은 부트스트랩 표본에서의 **짝비교**가 됩니다(`paired_bootstrap`).
- 모델 간 차이(예: AUUC_X − AUUC_CF)의 분포에서 백분위 95% 구간을 계산할 예정입니다.

**비용 실측.**
- 조건: 검증 세트 2,795,918행, 실제 T·Y 사용, 모델 대신 무작위 점수 3종(1종은 동점 다수). 최종 테스트 세트는 사용하지 않았습니다.

| 항목 | 실측 |
|---|---|
| 검증 세트 T·Y 로드 | 6.5초 |
| 1회 평가 (정렬 포함) | 0.34초 (정렬 0.24초) |
| 부트스트랩 1회 × 3모델 | 0.33초 → B=1,000이면 약 5.5분(추정) |
| 최대 RSS | 679 MB |

대규모 부트스트랩은 실행하지 않았습니다(5회만 시간 측정).

메모리는 관측치 수 × (점수 8 B + 가중치 4 B + 누적 배열)에 비례하며, 모델 수와 무관하게 수백 MB 수준입니다. 무작위 점수의 정규화 AUUC는 0.021로 0에 가까워 기대대로입니다.

## 9. STEP 5-3 파일럿 학습 계획 (제안)

1. **학습:** `train_100000`으로 T-Learner, X-Learner, Causal Forest를 학습합니다. STEP 4의 사전 고정 하이퍼파라미터를 쓰고, X-Learner와 CF의 성향점수는 상수 0.85입니다.
   - Y가 이진이므로 결과 모델은 기존 `RandomForestRegressor`(확률 회귀)를 그대로 씁니다. 바꿀 경우 사전에 기록합니다.
2. **실측:** 모델별 학습 시간, 최대 메모리, 검증 세트(또는 그 층화 부분표본) 예측 시간을 `memory_guard.py`로 감시하며 측정합니다.
3. **확장 판단:** 측정 결과로 `train_300000`, `train_1000000` 확장 가능성을 판단합니다(STEP 3-1과 같은 방식).
4. **평가 데이터 분리:** 파일럿 평가는 **검증 세트에서만** 합니다. 최종 테스트는 모델·크기·설정이 모두 확정된 뒤 한 번만 사용합니다.
5. **점검 항목:** 100k의 대조군 전환 29건이라는 한계를 점검합니다. 예측 점수 분포와 동점 비율, 검증 Qini 곡선의 정의 불가 격자점 여부를 봅니다.
