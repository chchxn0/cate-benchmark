# STEP 6-2 최종 연구 결론

- 작성일: 2026-11-11
- 모든 결론은 검증된 결과 파일(`results/tables/step6_*.csv`, 36개 점검 통과)에 근거합니다.
- 시뮬레이션 결론은 RMSE(정답 대비 오차), 실제 데이터 결론은 Qini(타기팅 성과) 기준입니다.

## 1. 항목별 결론

### ① 표본 크기

시뮬레이션(p=0.5, 선형)에서 표본을 1,000 → 100,000으로 늘리자 CATE 추정 RMSE가 다음처럼 줄었습니다.

| 모델 | 1,000 | 100,000 | 변화 |
|---|---|---|---|
| T-Learner | 0.380 | 0.221 | −41.8% |
| X-Learner | 0.276 | 0.123 | −55.4% |
| Causal Forest | 0.209 | 0.062 | −70.3% |

- 모든 구간 비교가 유의했고(Holm 보정), 30회 반복 모두에서 감소했습니다. 이질성을 학습하지 않는 Constant ATE는 변화가 유의하지 않았습니다.
- **결론: 표본이 클수록 세 모델 모두 정확해지며, 데이터 증가의 이득은 Causal Forest가 가장 컸습니다.**
- Criteo 검증 세트에서도 학습 100k → 300k에서 같은 방향의 개선이 보였습니다. 짝 부트스트랩 구간이 0을 제외한 것은 Causal Forest(+272)뿐입니다. 모델당 1회 학습이라 이것은 관찰된 경향으로만 봅니다.

### ② 처치군 불균형

- 처치군 비율이 50% → 10%로 줄자 세 모델의 RMSE가 모두 유의하게 증가했습니다(T +13.5%, X +32.4%, CF +48.8%).
- T-Learner는 p=0.1에서 Constant ATE보다 유의하게 나빴습니다(+0.018, T가 더 나았던 반복 3/30). n=1,000에서도 마찬가지였습니다(+0.071).
- 30% 수준에서는 X만 유의하게 나빠졌습니다.
- **결론: 처치군이 크게 부족하면 모든 모델의 정확도가 떨어지며, 집단별 모델을 따로 학습하는 T-Learner가 가장 취약합니다.**
- 실제 데이터(대조군 15%, 전환율 0.29%)에서도 T-Learner는 예측의 83.6%가 0이 되고 Qini가 가장 낮아, **같은 방향의 현상**을 보였습니다. 조건이 같은 실험은 아니므로 직접 대응시키지는 않습니다.

### ③ 처치효과 구조

| 효과 구조 | 가장 정확한 모델 | X − CF RMSE 차이 | 판정 |
|---|---|---|---|
| 선형 | **Causal Forest** | X가 0.069 더 큼 | 유의 (선형 5개 조건 모두) |
| 상호작용 | **X-Learner** | −0.025 [−0.029, −0.022] | 유의, X 우세 30/30 |
| 비선형 | 구분 불가 | −0.006 [−0.011, 0.0001] | Holm p = 0.106, 비유의 |

- 보조 분석 결과, 상호작용 조건의 X 우위는 MAE에서는 나타나지 않았습니다(p = 0.87).
- **결론: 최적 모델은 효과 구조에 따라 달라집니다.** 선형 효과에는 Causal Forest, 상호작용 효과에는(RMSE 기준) X-Learner가 적합했습니다. 비선형 효과에서는 둘 중 어느 쪽이 낫다고 말할 수 없습니다. Causal Forest는 효과 구조가 복잡해질 때 오차 증가가 가장 컸습니다(+96%, +127%).

### ④ 실제 Criteo 데이터

최종 테스트 2,795,918명, 학습 300k 기준 Qini coefficient입니다.

| 모델 | Qini [95% CI] |
|---|---|
| T-Learner | 399 [230, 565] |
| X-Learner | 692 [529, 858] |
| Causal Forest | 685 [522, 847] |

- 세 모델 모두 무작위 타기팅보다 우수했습니다(사전 기준: 95% CI > 0).
- X − T(+292)와 CF − T(+286)는 Bonferroni 보정 후에도 유의했습니다. CF − X(−6)는 유의하지 않았습니다.
- 예측 상위 10% 고객 타기팅의 추정 증분 전환은 1,677~1,934건으로, 무작위(322건)의 약 5~6배입니다.
- **결론: 실제 광고 데이터에서도 CATE 모델로 효과가 큰 고객을 선별할 수 있었습니다. X-Learner와 Causal Forest가 T-Learner보다 우수했고, 두 모델 간 차이는 확인되지 않았습니다.**

### ⑤ 종합 결론

- **일관된 결과**: 세 모델의 성능은 데이터 특성에 따라 체계적으로 달라졌습니다. 그중 가장 일관된 결과는 **T-Learner의 열세**입니다. 시뮬레이션 7개 조건 모두에서 RMSE가 가장 컸고, 실제 데이터에서도 Qini가 유의하게 가장 낮았습니다.
- **조건에 따라 달라진 결과**: Causal Forest와 X-Learner의 우열은 조건에 따라 달랐습니다.
  - 선형 효과, 충분한 표본, 처치 불균형 조건의 시뮬레이션에서는 Causal Forest가 가장 정확했습니다.
  - 상호작용 효과에서는 X-Learner가 RMSE 기준으로 우수했습니다.
  - 비선형 효과와 실제 광고 데이터에서는 두 모델이 통계적으로 구분되지 않았습니다.
- **실무적 시사점(단, 이 연구 조건 안에서)**: 처치·대조 집단이 불균형하거나 결과가 희귀한 환경에서는 T-Learner보다 X-Learner나 Causal Forest를 우선 고려할 수 있습니다. 둘 중 하나를 고르려면 데이터의 효과 구조와 계산 비용을 함께 고려해야 합니다.
  - 계산 비용 예: Criteo 300k 학습 시 X 177초 / 1.4 GB, CF 726초 / 3.8 GB.

## 2. 상세 결과 해석 버전

본 연구는 고객별 처치효과(CATE)를 추정하는 세 모델, T-Learner·X-Learner·Causal Forest를 정답을 아는 시뮬레이션과 실제 광고 데이터에서 같은 조건으로 비교했습니다.

**시뮬레이션.** 기준 조건(n=10,000, 처치 50%, 선형 효과)에서 한 번에 한 요인만 바꾼 7개 조건을 각각 30회 반복했습니다. 같은 반복 안에서 모델 간 짝비교를 하고 Holm 다중검정 보정을 적용했습니다.
- **표본 크기**: 표본이 커질수록 세 모델의 정답 대비 오차(RMSE)가 모두 유의하게 줄었습니다. Causal Forest의 감소율(1k → 100k, −70.3%)이 가장 컸습니다.
- **처치 불균형**: 처치군 비율이 10%로 줄면 모든 모델의 오차가 유의하게 커졌습니다. T-Learner는 이질성을 무시한 Constant ATE보다도 부정확해졌습니다. 이 현상은 표본이 1,000명일 때도 나타났습니다.
- **효과 구조**: 선형 효과에서는 Causal Forest가 모든 표본 크기와 처치 비율 조건에서 가장 정확했습니다. 효과가 비선형이거나 상호작용 형태가 되면 Causal Forest의 오차가 약 2배로 커졌습니다. 그 결과 상호작용 조건에서는 X-Learner가 RMSE 기준으로 유의하게 더 정확했고, 비선형 조건에서는 두 모델이 구분되지 않았습니다.
- 상호작용 조건의 X 우위는 MAE 기준으로는 나타나지 않았습니다. 따라서 이 결론은 큰 오차에 민감한 RMSE에 한정됩니다.

**실제 데이터.** Criteo 광고 데이터(1,398만 명, 처치 85%, 전환율 0.29%)에서 30만 명으로 학습한 모델을 별도의 테스트 고객 279만 명에서 한 번 평가했습니다. 정답 효과가 없으므로, 예측 순위에 따른 증분 전환(Qini·AUUC)으로 평가했습니다.
- 세 모델 모두 무작위 타기팅보다 유의하게 높은 Qini coefficient를 보였습니다.
- 예측 상위 10% 고객만 타기팅해도 무작위 대비 약 5~6배의 증분 전환이 추정되었습니다.
- X-Learner(692)와 Causal Forest(685)는 T-Learner(399)보다 유의하게 높았습니다. 두 모델 간 차이는 통계적으로 확인되지 않았습니다.
- T-Learner는 대조군 전환이 매우 적은 환경에서 테스트 고객의 83.6%에 대해 같은 값(0)을 예측해, 고객 순위를 구분하는 능력이 제한되었습니다.
- 검증 세트에서 수치상 앞섰던 Causal Forest의 X-Learner 대비 우위는 테스트에서 재현되지 않았습니다.

**한계.** 이 결과는 하나의 시뮬레이션 데이터 생성 구조, 고정 하이퍼파라미터, 한 번에 한 요인만 바꾼 설계, 그리고 실제 데이터에서 모델당 한 번의 학습에 기반합니다. 다른 데이터나 설정으로 일반화하려면 추가 검증이 필요합니다.

## 3. 발표용 핵심 결론 5문장 버전

1. 표본이 커질수록 세 모델의 CATE 추정 오차는 모두 줄었고, 특히 Causal Forest는 데이터 100배 증가 시 오차가 70% 감소했습니다.
2. 처치군이 10%로 줄면 모든 모델이 부정확해졌으며, T-Learner는 '모두에게 같은 효과'를 예측하는 기준선보다도 나빴습니다.
3. 선형 효과에서는 Causal Forest가, 상호작용 효과에서는 X-Learner가 더 정확했고, 비선형 효과에서는 두 모델의 차이가 통계적으로 확인되지 않았습니다.
4. 실제 Criteo 광고 데이터에서는 세 모델 모두 무작위 타기팅보다 우수했으며, 예측 상위 10% 고객만 타기팅해도 약 5~6배의 증분 전환이 추정되었습니다.
5. 실제 데이터에서 X-Learner와 Causal Forest는 T-Learner보다 유의하게 우수했지만 서로 간의 차이는 확인되지 않아, 최적 모델은 데이터 특성에 따라 달라진다는 결론을 얻었습니다.

## 4. 발표 마지막 결론 3문장 버전

1. CATE 모델의 성능은 표본 크기, 처치군 비율, 효과 구조에 따라 체계적으로 달라지며, 하나의 모델이 모든 조건에서 최선은 아니었습니다.
2. 시뮬레이션과 실제 광고 데이터 모두에서 T-Learner가 가장 약했고, X-Learner와 Causal Forest가 더 정확하거나 더 나은 타기팅 성과를 보였습니다.
3. 실제 데이터에서 예측 상위 10% 고객 타기팅은 무작위 대비 약 5~6배의 증분 전환을 보여, 데이터 특성에 맞는 CATE 모델 선택이 효율적인 타기팅의 출발점임을 확인했습니다.

## 5. 연구 기여와 차별점

새로운 CATE 알고리즘을 개발하지 않았습니다. 기여는 **기존 대표 모델 세 가지를 통제된 조건과 실제 데이터에서 체계적으로 비교·검증한 것**에 있습니다.

| 실제로 수행한 내용 | 구체적 내용 |
|---|---|
| 세 모델의 동일 조건 비교 | 같은 기본 학습기·하이퍼파라미터·seed 규칙·데이터 분할. 같은 반복의 모델끼리 짝비교 |
| 데이터 특성의 체계적 변화 | 표본 크기(1k~100k), 처치 비율(0.5~0.1), 효과 구조(선형·비선형·상호작용). 효과 평균과 SD를 고정하고 모양만 바꾸도록 설계 |
| 반복 실험과 통계 검정 | 7개 조건 × 30회 반복(210회). 신뢰구간, 짝비교, Holm 보정. 유의하지 않은 결과(비선형 X vs CF)도 그대로 보고 |
| 실제 conversion 기반 평가 | Criteo v2.1 수정판 1,398만 행. 캠페인 배정(ITT)과 전환(conversion)을 그대로 사용. 테스트 세트를 학습·선택과 완전히 분리해 한 번만 평가 |
| 희귀 전환·불균형 환경 분석 | 전환율 0.29%, 대조군 15%. 과대표집 없이 비례 층화. T-Learner의 동점 예측(83.6%) 현상을 정량화 |
| 타기팅 성과와 불확실성 | 불균형을 보정한 Qini·Uplift·AUUC를 직접 구현하고 단위 테스트로 검증. 처치·대조 층화 짝 부트스트랩(B=1,000)과 Bonferroni 보정. 상위 10/20/30% 증분 전환 신뢰구간 |
| 재현성 | 설정·분할 인덱스·모델 파일 SHA-256 기록, 자동 테스트 112개, 결과 재검증 스크립트 |

**기존 문헌과의 관계**: 확인 가능한 범위에서만 적습니다.
- X-Learner는 Künzel et al.(2019)이 처치·대조 집단 크기가 불균형할 때를 고려해 제안한 메타러너입니다. 본 연구의 처치 비율 실험에서 X-Learner는 T-Learner보다 일관되게 정확했습니다. 다만 선형 효과 조건에서는 Causal Forest가 더 정확했습니다.
- Causal Forest(Wager & Athey, 2018; Athey et al., 2019)와 Criteo 데이터(Diemert et al., 2018)는 원 논문의 방법과 데이터를 그대로 사용했습니다.
- 원 논문들의 수치 결과와 본 연구 결과를 직접 비교하지는 않았습니다. 모델 설정과 평가 방식이 다르기 때문입니다.
