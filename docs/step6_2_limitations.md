# STEP 6-2 연구의 한계와 해석상 주의사항

- 작성일: 2026-11-11
- 결론(`step6_2_final_conclusions.md`)을 해석할 때 함께 봐야 하는 한계입니다. 각 항목에 **결과에 미치는 영향**과 **이 연구에서 한 대응**을 같이 적었습니다.

## A. 시뮬레이션 설계

| 한계 | 내용 | 영향 | 이 연구의 대응 |
|---|---|---|---|
| 단일 데이터 생성 구조 | 정규 공변량 10개, 무작위 배정(교란 없음), 고정된 기저 결과 $\mu_0$, 잡음 SD 1, 효과 함수는 구조마다 하나 | 다른 공변량 분포·교란·잡음 수준에서는 순위가 달라질 수 있음 | 결론을 "이 데이터 생성 구조에서"로 한정 |
| OFAT 설계 | 기준 조건에서 한 요인씩만 변경(7개 조건) | 작은 표본 × 불균형, 비선형 × 불균형 같은 **요인 간 교호작용은 검증하지 않음** | 27개 조건 완전요인설계는 코드에 구현만 되어 있고 실행하지 않았음을 명시 |
| 효과 구조별 분포 모양 차이 | 세 구조의 평균(0.5)과 SD(0.3)는 같지만, 비선형은 오른쪽으로 치우침(skew ≈ 1), 상호작용은 꼬리가 두꺼움 | 구조 간 RMSE 차이에 "모양" 외의 분포 특성이 섞임 | 해석 시 함께 고려하도록 명시 |
| 고정 하이퍼파라미터 | 모든 조건에서 RF 200그루, `min_samples_leaf=5`(CF 1,000그루) | 조건별 튜닝 시 순위 변화 가능. "각 모델의 최고 성능" 비교가 아님 | 실험 전에 고정해 공정성 확보 |
| 테스트 크기와 표본 크기 연동 | 테스트 = 전체의 20%(200~20,000개) | n이 클 때 반복 간 SD 감소의 일부는 측정 잡음 감소 | 해석에 명시 |
| 지표 선택 | RMSE 기준 결론. 상호작용 조건의 X 우위는 MAE에서는 사라짐(보조 분석 p = 0.87) | 지표에 따라 결론이 달라질 수 있음 | RMSE 기준임을 명시, MAE 보조 결과 공개 |
| 다중검정 범위 | Holm 보정은 비교 묶음 안에서만 적용 | 연구 전체의 모든 검정을 아우르지 않음 | 보정 범위를 표마다 표기 |

## B. 실제 Criteo 데이터

| 한계 | 내용 | 영향 | 이 연구의 대응 |
|---|---|---|---|
| 모델당 단일 학습 seed | 각 모델을 300k 표본, seed 42로 한 번만 학습 | 부트스트랩 구간은 **테스트 표본 변동만** 반영. 학습 변동을 넣으면 구간이 더 넓어질 수 있음 | 모든 보고서에 명시. 검증과 테스트에서 일관된 결과(CF > T)를 우선 강조 |
| 낮은 conversion 비율 | 전환율 0.292%. 학습 300k의 대조군 전환 87건 | 결과 모델이 대부분 0을 예측. 상위 구간 비교의 불확실성이 큼 | 과대표집 없이 큰 테스트 세트(대조군 전환 813건) 확보 |
| 처치·대조 불균형 | 처치 85% / 대조 15% | 단순 건수 비교는 편향. 대조군 쪽 학습 정보 부족 | 집단별 분모를 쓰는 Qini, 처치·대조 층화 부트스트랩 사용 |
| T-Learner 동점 예측 | 테스트 예측의 83.6%가 정확히 0 | 해당 구간에서는 순위 정보가 없음. 평가는 무작위 순서 기댓값으로 처리 | 동점 블록 보간을 평가 정의에 포함하고 비율을 보고 |
| 학습 규모 | 1,100만 행 중 30만 행만 학습 | 더 큰 규모에서 순위가 달라질 수 있음(100k → 300k에서 CF가 가장 크게 개선된 경향) | 16 GB 메모리 실측 근거(CF 1M ≈ 9~11 GB 추정)로 규모 결정 |
| ITT vs 노출 효과 | 추정 대상은 캠페인 **배정** 효과. 처치군 중 실제 노출은 3.6% | "광고를 본 사람"의 효과로 해석 불가 | exposure를 처치나 입력으로 쓰지 않음 |
| 데이터 특성 | 익명화·무작위 투영된 특성, 비균일 서브샘플링(공식 설명), 단일 출처 | 다른 기간·광고주·국가로 일반화할 수 있는지 알 수 없음 | 결론을 "이 데이터에서"로 한정 |
| 중복 특성 행 | 특성 벡터가 같은 행이 11.6%, 사용자 ID 없음 | 분할 간에 같은 특성이 섞일 수 있어 다소 낙관적 평가 가능 | 제거하지 않고 한계로 기록 |
| 검증 데이터 기반 학습 규모 선택 | 300k 결정에 검증 세트 결과(CF 개선)를 참고 | 선택 편향 가능성 | 설정을 고정하고 SHA-256을 기록한 뒤 테스트 세트는 1회만 사용 |
| 사후 탐색 분석 | 하위 3% 고객군의 높은 전환율 차는 결과를 본 뒤 정한 분석 | 확증 근거가 아님 | 결론에서 제외 |

## C. 시뮬레이션과 실제 데이터의 연결

| 한계 | 내용 |
|---|---|
| 평가 목적의 차이 | 시뮬레이션 RMSE는 **고객별 효과 크기의 정확도**를, Qini는 **효과 순위에 따른 타기팅 성과**를 봅니다. 순위가 정확해도 크기 추정은 틀릴 수 있고, 그 반대도 가능합니다. 두 수치를 같은 척도로 비교하지 않습니다. |
| 조건의 비대응 | Criteo는 하나의 관측 환경이므로, 시뮬레이션의 선형·비선형·상호작용 조건이나 처치 비율 조건과 일대일로 대응시킬 수 없습니다. 두 결과가 같은 방향일 때도 "일관된 현상"으로만 표현합니다. |
| 불균형 방향 | 시뮬레이션은 **처치군**이 적은 경우(10%)를, Criteo는 **대조군**이 적은 경우(15%)를 다룹니다. |

## D. 결과를 표현할 때 지켜야 할 원칙

- 유의하지 않은 차이(비선형 X vs CF, Criteo X vs CF, 상위 10% 모델 간 차이)를 "더 좋다"고 쓰지 않습니다.
- 모델별 신뢰구간이 겹친다는 이유만으로 "차이가 없다"고 하지 않습니다. 짝비교 결과로 판단합니다.
- "광고 노출이 전환을 N건 늘린다" 같은 인과 주장을 하지 않습니다(ITT 추정치).
- 새로운 알고리즘 개발로 표현하지 않습니다.
